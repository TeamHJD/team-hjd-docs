# TeamHJD Docs에 오신 것을 환영합니다

이곳은 지식을 쌓아두는 서랍이 아니라, **팀이 같은 방식으로 판단하고 작업하도록 돕는 안내서**입니다.

## 처음이라면

아래 순서를 권장합니다. 앞 문서가 다음 문서의 맥락이 되도록 구성했습니다.

1. [협업의 전체 흐름](./collaboration/overview) — 작업이 Issue에서 Done까지 가는 모습을 먼저 봅니다.
2. [Git 기초](./collaboration/git-basics) — 흐름을 이루는 최소 개념을 익힙니다.
3. [GitHub 작업 흐름](./collaboration/github-flow) — 실제 팀 작업 단위를 이해합니다.
4. [Pull Request와 리뷰](./delivery/pull-request) — 변경을 팀에 반영하는 기준을 확인합니다.

## 중요도 표기

| 표기 | 의미 | 언제 읽나요? |
| --- | --- | --- |
| **필수** | 팀 작업을 시작하기 위한 공통 언어 | 첫 작업 전 |
| **중요** | 작업 품질과 협업 효율에 직접 영향 | 해당 작업 전 |
| **참고** | 막혔을 때 깊게 보는 보조 지식 | 필요할 때 |

문서가 길어도 모두 한 번에 외울 필요는 없습니다. 지금 하고 있는 작업과 연결된 다음 한 단계만 확인하면 됩니다.
