# 문서 중요도와 읽는 법

문서를 전부 정독하는 대신, 현재 상황에서 필요한 문서부터 읽습니다.

| 중요도 | 기준 | 예시 |
| --- | --- | --- |
| **필수** | 팀의 공통 작업 흐름을 이해하는 데 반드시 필요 | Git 기초, Issue → PR 흐름, 팀 작업 약속 |
| **중요** | 특정 작업의 품질·속도·안전에 큰 영향을 줌 | PR 리뷰, CI, Unity 에셋 협업 |
| **참고** | 필요한 순간 빠르게 확인하는 지식 | Git 명령어, 용어, 사례 |

## 작성자 기준

새 문서에는 맨 위에 중요도와 “언제 읽나요?”를 적습니다. 한 문서에서는 독자가 다음에 읽을 문서를 1~3개 이내로 안내합니다. 이렇게 하면 목차가 커져도 길을 잃지 않습니다.
