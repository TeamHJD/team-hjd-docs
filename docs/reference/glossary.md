# 용어 사전

> **중요도: 참고** · 낯선 단어를 만났을 때 빠르게 확인합니다.

| 용어 | 짧은 뜻 |
| --- | --- |
| Backlog | 아직 착수하지 않은 작업 후보 목록 |
| Blocker | 작업 진행을 막는 의존성 또는 문제 |
| CI | 변경 사항을 자동으로 통합·검증하는 과정 |
| Definition of Done | 작업을 정말 완료로 판단할 기준 |
| Regression | 기존에 되던 기능이 변경 후 다시 깨지는 현상 |

용어를 추가할 때에는 사전식 정의뿐 아니라 TeamHJD에서 어떤 상황에 쓰는지도 함께 기록합니다.
