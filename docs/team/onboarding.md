# 온보딩 실습

> **중요도: 필수** · 읽는 것에서 끝나지 않고 한 번 직접 경험합니다.

## 목표

Issue 생성부터 Branch 작업, Pull Request, Review 반영, Merge까지 한 사이클을 직접 완료합니다.

## 실습 흐름

1. 저장소를 Clone하고 로컬 환경을 확인합니다.
2. Issue를 만들고 작업 Branch를 생성합니다.
3. 작은 변경을 Commit하고 Push합니다.
4. PR을 열고 리뷰를 요청합니다.
5. 피드백과 CI를 반영한 뒤 Merge합니다.

각 단계의 상세 설명과 Git 명령어는 [전체 Unity 협업 가이드](../collaboration/unity-team-collaboration-guide)의 **온보딩 실습**에서 확인합니다.
