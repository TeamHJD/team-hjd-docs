# Git 기초

> **중요도: 필수** · Branch, Commit, Push, Pull을 처음 쓰기 전에 읽습니다.

Git은 “누가 언제 무엇을 바꿨는지”를 기록하며, 여러 사람이 같은 프로젝트를 안전하게 다루게 하는 버전 관리 시스템입니다.

## 꼭 알아둘 네 가지

| 개념 | 한 줄 설명 |
| --- | --- |
| Repository | 프로젝트와 변경 이력이 저장되는 공간 |
| Branch | 독립적으로 작업하는 흐름 |
| Commit | 의미 있는 변경을 남긴 이력 단위 |
| Push / Pull | 원격 저장소와 변경을 주고받는 동작 |

다음에는 이 개념들이 Issue와 PR 속에서 어떻게 연결되는지 봅니다: [GitHub 작업 흐름](./github-flow).
